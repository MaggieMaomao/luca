# Security Policy

## Supported versions

Luca is pre-1.0; security fixes land on the latest `main` and the most recent
published `@luca-game/engine` / `@luca-game/platform` releases.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report privately to **maggie.jingxi.zhang@gmail.com** (or use GitHub's
["Report a vulnerability"](https://github.com/MaggieMaomao/luca/security/advisories/new)
private advisory flow). Include:

- a description of the issue and its impact,
- steps to reproduce (a minimal repro if possible),
- affected version(s).

You'll get an acknowledgement as soon as possible. Please allow reasonable time
for a fix before any public disclosure. Thank you for helping keep Luca and its
users safe.
