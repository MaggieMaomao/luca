# Capacitor Mobile App

> **Status:** Scaffolding complete. Build works on web. Android and
> iOS native shells are generated. The APK can't be built on this
> machine (no Android SDK installed) — see [Build a real APK](#build-a-real-apk)
> for the steps to do it elsewhere.

## What this is

The luca mobile app is a Capacitor-wrapped web app that ships the
basketball game (and future real-time games) as native iOS/Android
binaries. It's the deployment layer for the luca platform.

```
luca mobile app
├── web (React + Vite)        ← the basketball game + gallery
├── Android (gradle project)  ← generated by `cap add android`
└── iOS (Xcode project)       ← generated by `cap add ios`
```

One codebase, three platforms. The luca engine + platform packages
provide the game logic; this app provides the native shell.

## Quick start

```bash
# Install dependencies
cd app
npm install

# Run the web app in dev mode (browsers only — for testing)
npm run dev

# Build the web bundle (for Capacitor)
npm run build

# Sync the web bundle to native projects
npx cap sync

# Open in Android Studio
npx cap open android

# Open in Xcode
npx cap open ios
```

## Architecture

### Files

```
app/
├── package.json              ← Capacitor + React + luca packages
├── vite.config.ts            ← Vite bundler config
├── capacitor.config.json     ← Capacitor app + plugin config
├── tsconfig.json
├── index.html                ← web entry
├── main.tsx                  ← React entry (BrowserRouter, gallery, basketball route)
├── index.css                 ← global styles
├── src/
│   └── capacitor-init.ts     ← native plugin wiring (StatusBar, SplashScreen, etc.)
├── android/                  ← generated by `cap add android`
├── ios/                      ← generated by `cap add ios`
└── dist/                     ← web bundle (built by `npm run build`)
```

### Native plugins

| Plugin | Purpose |
|---|---|
| `@capacitor/status-bar` | Match the dark theme (`#1a1f2e`) and use dark icons |
| `@capacitor/splash-screen` | 1.5s basketball-themed splash on cold start |
| `@capacitor/haptics` | Shot release haptic (medium impact) + make/miss haptic (light impact) |
| `@capacitor/network` | Listen for offline/online transitions (basketball is single-player, so just logs) |

All plugins are wrapped in `try/catch` so they're best-effort —
failures don't crash the app.

### How the basketball game ships

The basketball game lives in `@luca-game/platform/games/basketball`.
The luca mobile app imports it via `@luca-game/platform/games/basketball`
(lazy-loaded in `BasketballScreen`). Capacitor's Vite-based bundler
inlines it into `dist/`. On `npx cap sync`, the dist is copied to
`android/app/src/main/assets/public/` and `ios/App/Public/`.

When the user runs the app:
1. Capacitor launches the WebView at `assets/public/index.html` (Android)
2. React renders the gallery (`/`)
3. User taps the basketball card → route to `/game/basketball`
4. BasketballScreen lazy-loads the game, mounts `<RealTimeGameHost>`
5. The engine spins up the PixiJS renderer + Matter.js physics
6. User swipes → throw system → ball flies → scoring

## Build a real APK

> Requires Android SDK + JDK 17+ on the build machine.

```bash
# 1. Install Android Studio (or just the SDK command-line tools)
#    https://developer.android.com/studio
#
# 2. Set ANDROID_HOME environment variable
export ANDROID_HOME=$HOME/Android/Sdk
export PATH=$PATH:$ANDROID_HOME/cmdline-tools/latest/bin:$ANDROID_HOME/platform-tools

# 3. Accept the SDK licenses
sdkmanager --licenses

# 4. Install required SDK packages
sdkmanager "platforms;android-34" "build-tools;34.0.0" "platform-tools"

# 5. Sync the web bundle + native config
cd luca/app
npm run build
npx cap sync android

# 6. Build a debug APK
cd android
./gradlew assembleDebug
# Output: app/build/outputs/apk/debug/app-debug.apk

# 7. Install on a connected device
adb install -r app/build/outputs/apk/debug/app-debug.apk

# 8. Or build a release APK (requires signing config)
./gradlew assembleRelease
# Output: app/build/outputs/apk/release/app-release-unsigned.apk
```

## Build an iOS IPA

> Requires macOS with Xcode 15+ and CocoaPods.

```bash
# 1. Install Xcode + CocoaPods
xcode-select --install
sudo gem install cocoapods

# 2. Sync the web bundle + native config
cd luca/app
npm run build
npx cap sync ios

# 3. Install iOS dependencies
cd ios/App
pod install

# 4. Open in Xcode
open App.xcworkspace

# 5. Configure signing in Xcode (Signing & Capabilities → Team)
# 6. Build → Run on simulator or device
```
